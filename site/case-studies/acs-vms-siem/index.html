Independent documentary case study

Evidence-Driven ACS/VMS to SIEM Integration Feasibility

Commercial physical-security applications produce several event families. This study evaluates which application security events could support SIEM use cases and what a lab must verify first.

Open the interactive explorer

The engineering challenge

A door unlock reports activity in the physical domain. A successful or failed operator login, a role change, and an application audit configuration change describe the security of the application itself. Each needs its own collection and attribution checks.

Research methodology

  1. Qualify the OEM and deployment. Record the evaluated product, build, platform, licensing and lab-access constraints.
  2. Map requirement-level telemetry. Separate application availability, export availability and field support. Record claim source and limitations.
  3. Gate first, then compare. Use weighted criteria to compare viable candidates and state unknowns and uncertainty explicitly.
  4. Plan independent validation. Define transport, semantics and correlation checks before integration.

Proposed Wazuh architecture

Each handoff is a validation dependency. Supported collection paths depend on the evaluated build.

  1. Application auditEstablish event class and source identity.
  2. Supported audit exportConfirm representation, entitlement and completeness.
  3. Secure collectionUse a read-only collector, a Wazuh Agent or an approved intake.
  4. Wazuh ManagerReconcile receipt before parsing and normalization.
  5. Host correlationJoin application and host evidence with justified identity and time bounds.

PoC readiness

Prospective acceptance areas. Each layer remains open and must be assessed separately.

L1 · Transport

Reconcile a known source event with raw receipt and capture recovery results across restart and rotation.

L2 · Semantics

Validate actor, action, target, timestamp and outcome against an approved reference.

L3 · Correlation

Justify identity and time matching, then test ambiguity and alternative explanations.
