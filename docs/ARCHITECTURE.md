# Proposed collection design

Application audit flows through a documented, supported export to a restricted collector, Wazuh Agent or approved intake. The Wazuh Manager first captures raw receipt. Reconcile source counts and test restart and rotation before parsing. Preserve evidence provenance during normalization. Correlate with a separate approved host signal only where identity and event time support the join.

Exact build, licensing, deployment, export and parser prerequisites remain subject to validation.
