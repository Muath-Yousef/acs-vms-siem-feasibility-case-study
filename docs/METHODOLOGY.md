# Research method

1. Identify OEM, exact evaluated build, deployment, support and licensing constraints.
2. Map requirement-level event origin, supported export and field fidelity. Keep application security audit separate from host, physical and device events.
3. Record source, version and uncertainty per claim. Distinguish documented capability, proposed design and hypothetical input.
4. Gate mandatory events, supported path, entitlements, blocking dependencies and receiving compatibility.
5. Compare viable options using weighted criteria, unknown handling and sensitivity testing. A high score cannot clear a failed gate.
6. Turn unresolved claims into separate empirical transport, semantics and correlation criteria.
