# ACS/VMS application telemetry for SIEM

Can an operator action in a commercial ACS/VMS application be captured in its audit trail and delivered to Wazuh through a supported intake? Physical events were considered separately. Authentication, privilege and configuration changes were evaluated for applicability, documented export and required fields.

AXIS Camera Station Pro was the first candidate for a transport experiment because the assessed documentation describes continuous plain-text audit and event exports. Raw receipt, rotation and field fidelity remain open. Genetec Security Center offered the strongest documented application-security event coverage among the assessed products. Evaluation access, export completeness and data fidelity remain dependencies.

The documentary assessment supports scoping a PoC for intake. Empirical testing remains open. Production suitability is undetermined.
