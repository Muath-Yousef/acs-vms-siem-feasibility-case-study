# Validation boundaries

| Layer | Status | Acceptance evidence |
| --- | --- | --- |
| Documentary feasibility | PASS | Build-specific support and traceable source limitations |
| L1 transport | OPEN | Known raw inputs reconciled with receipt, restart and recovery |
| L2 semantics | OPEN | Exported actor, action, target, timestamp and outcome match observed action |
| L3 correlation | OPEN | Justified identity and timing linkage with ambiguity tests |
| Production suitability | UNDETERMINED | Separate security, operations and support acceptance |

The simulator uses illustrative states. Its GO means only that hypothetical feasibility gates clear.
